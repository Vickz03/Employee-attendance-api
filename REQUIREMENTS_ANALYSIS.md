## 2. Defects Identified in Starter `app/main.py`

1. **`GET /health` false positive**: Returns `{"status": "ok"}` unconditionally without checking if MongoDB is reachable. Should ping DB and return 503 if unreachable.
2. **`create_employee` check-then-insert race**: Uses `find_one` then `insert_one` without catching `DuplicateKeyError`, allowing duplicate `emp_code` under concurrent requests.
3. **`create_employee` shift validation**: Does not validate `shift_start != shift_end` as required by the contract.
4. **`create_employee` response timestamp**: Stores `datetime.now()` (local naive time instead of UTC BSON date), does not return epoch milliseconds in `created_at`.
5. **`list_employees` pagination offset bug**: Calculates `skip = page * page_size`, which skips page 1 entirely! Correct formula is `(page - 1) * page_size`.
6. **`list_employees` total count bug**: Computes `total = db.employees.count_documents({})` which ignores the `department` filter.
7. **`list_employees` missing sort**: Fails to sort by `emp_code` ascending as required by the contract.
8. **`punch_in` local date vs IST date**: Computes `ts.date().isoformat()` using local time instead of IST calendar date with R1 overnight shift logic.
9. **`punch_in` check-then-insert race condition**: Queries `find_one` then `insert_one`. Simultaneous punch-ins for the same employee and date both succeed or corrupt state.
10. **`punch_in` non-existent employee bug**: If `emp` is None, `emp["shift_start"]` raises an unhandled `TypeError` (resulting in a 500 error instead of 404).
11. **`punch_in` invalid response format**: Injects `"id": str(res.inserted_id)` which is not in OpenAPI schema, and fails to serialize `punch_in` as epoch milliseconds.
12. **`punch_in` timestamp truncation**: Fails to truncate instants to whole seconds as required by R1.
13. **`compute_late_minutes` timezone error**: Replaces hour and minute on naive/local datetime and performs naive subtraction; does not properly align with shift start in IST.
14. **`compute_work_hours` rounding bug**: Uses Python's built-in `round()`, which is Banker's rounding (round-to-even) instead of the required half-up rounding (R4).
15. **`compute_overtime` timezone & overnight bug**: Replaces hour and minute on `date_str` without accounting for overnight shift end falling on the next calendar day; also does not enforce the minimum 30-minute threshold (R3).
16. **`list_attendance` collection scan and memory load**: Does `docs = list(db.attendance_logs.find(q))` loading all documents into Python memory before sorting and pagination; will crash/timeout on 100k docs.
17. **`list_attendance` missing date range validation**: Does not validate `date_from > date_to` (must return 422).
18. **`list_attendance` response formatting**: Injects internal `id: str(d.pop('_id'))` and returns raw BSON datetimes instead of epoch milliseconds.
